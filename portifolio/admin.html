How to add a project

  1. Fill in the form and click Save Project.
  2. Click Copy Code.
  3. Open script.js in any text editor.
  4. Find the line const PROJECTS = [ and select everything from that line down to the matching ];
  5. Paste — it replaces the old array with your updated one.
  6. Save the file. Reload your portfolio — done.
